Impostor Viewer

Deferred sphere-impostor renderer · WebGL2

Source

Applied while reading, so a long trajectory can be thinned before it has to fit in memory. Several files import as one trajectory, ordered naturally by name — which is how a dump *.lammpstrj run comes off disk.

Bead radius

From spacing measures the median nearest-neighbour distance of the configuration and draws the bead at the σ/2 that implies (spacing ÷ 2·21/6, the Lennard-Jones minimum). It depends on the beads and not on how much empty box was dumped around them, so an imported file and the demos come out at the same size.

Trajectory

Writing the trajectory out as a video or a PNG sequence is under Export.

Periodic cell

For a dump written with unwrapped coordinates (xu yu zu, or x y z from a run with no image flags applied): every bead is shifted by whole box vectors until it lands inside the cell.

Copies of the cell on each side. One number applies to all three axes; three set them separately; a pair (left, right) sets the two sides of one axis apart. Fractions are a partial tile — 0.5 shows half a box further out, cut at that plane. 1,(0.5,0.25),2 is one full copy each way in x, half a box down and a quarter up in y, two each way in z.

Slices every bead at the cell boundary, so one crossing a seam hands its area continuously to the wrapped copy on the opposite face. With image copies on, the cut is at the outer edge of the tiled region.

Projection

Parallel projection — no foreshortening, so equal lengths stay equal anywhere in the box and a cube's edges stay parallel. Switching keeps the size at the point you are looking at, so nothing jumps. P toggles; 5 is the true isometric direction.

Director cap (the dot)

How wide the band and the cap are is geometry, not colour: it stays with band / bandsoft / capmin / capsoft in the scheme text below, and applies to every colouring mode.

Director source

The director is the axis the band and the cap are drawn about — it is what makes a bead orientable rather than a ball. A plain dump id type x y z carries none, so one is synthesised.

Scheme

#rrggbb is a display-space colour and is raised to display gamma on the way into the shader. Three bare floats are taken as linear light instead, so the values in render_style.py can be pasted in verbatim.

Still

The PNG is the viewport, pixel for pixel — what you see is what is written. For a bigger figure, hide the panel with H and make the window as large as the screen allows. Copy as Python puts the sliders back into your own renderer as a RenderStyle(…) literal for render_style.py.

Movie

WebM encodes each frame with a timestamp of its own, so the file is exactly the frame rate you asked for however long a frame took to draw — a scene that previews at 3 fps still writes a clean 60 fps video. MP4 is captured in real time instead, because H.264 is what drops straight into a slide deck; if the scene is too heavy to render in its slot the take falls behind, and it says so rather than pretending. Both are encoded in this tab and nothing is uploaded.

PNG sequence is the lossless route: one viewport-sized file per frame, numbered for ffmpeg -i %04d.png. The browser asks once to allow multiple downloads, and a second click stops it.

Settings

A settings file carries the render style, the colour scheme, the type colours and the camera — everything except the data. Loading one from a file restores the camera as well; reopening the page keeps only the angle, since the distance belongs to whatever was on screen when it was saved.

About

Seven passes, ported from lammps_live/ui/gl3d.py: instanced sphere impostors into a G-buffer (each bead one camera-facing quad, the sphere ray-cast per fragment so gl_FragDepth resolves intersections exactly), half-res ambient occlusion and a screen-space sun march, a foreground-masked blur of both, the lighting composite with outline, depth cue and half-strength ACES, a golden-angle depth of field, depth-tested box lines, then FXAA.

Everything after the first pass costs pixels, not beads — 200 000 beads post-process for the price of 7.

Reads dump custom trajectories (ITEM: ATOMS …, any column order, any number of frames), read_data files and .xyz — multi-frame or one file per frame. Nothing is uploaded anywhere: the file is parsed in this tab.

For a figure on paper: White at the top, Orthographic under Camera, and Publication (white) under Colour · Scheme, which moves the lighting to match.
